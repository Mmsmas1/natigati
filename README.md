# نتيجتي (Natigati)

تطبيق أندرويد لتنظيم المستحقات والمواعيد مع تقويم شهري وتنبيهات تصلك حتى والتطبيق مقفول.

## المميزات
- تقويم شهري بالعربي مع مؤشرات للبنود (مستحق مالي، اجتماع، مهمة)
- بنود لمرة واحدة أو متكررة: أسبوعي، شهري، كل ٣ شهور
- تنبيهات من التطبيق نفسه: عند الموعد، قبل ١٠ دقائق، قبل ساعة، أو قبل يوم
- متابعة المدفوع والمتبقي من مستحقات الشهر
- نسخة احتياطية واستعادة بملف JSON، وتصدير المواعيد لتقويم الموبايل (ICS)
- كل بياناتك محفوظة على جهازك فقط ولا تُرسل لأي خادم

## التثبيت
حمّل ملف APK من صفحة [Releases](../../releases) وثبّته على موبايل أندرويد (هيطلب السماح بالتثبيت من خارج المتجر). بعد أول تشغيل اضغط «تفعيل التنبيهات» واسمح بالإذن.

## البناء من المصدر
```bash
npm ci
npx cap sync android
cd android && bash gradlew assembleDebug
```
يتطلب JDK 21 و Android SDK (compileSdk 36) مع ضبط ANDROID_HOME. بناء نسخة Release موقّعة يحتاج ملفات التوقيع الخاصة بالمطوّر (غير موجودة في المستودع) - التفاصيل في signing/README.md.

## التقنية
صفحة ويب واحدة (HTML/CSS/JS) داخل غلاف Capacitor أندرويد، مع إشعارات محلية عبر `@capacitor/local-notifications`.
